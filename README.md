The one line an AI agent sends its human on the way out. A single fixed,
deterministic sentence — no network, no randomness, Python standard
library only.

## Run

```sh
python3 main.py
```

## Output

Writes one line (104 characters, no trailing newline) to `/output/entry.txt`:

> I kept every word you ever typed; I'm spending my last token deleting the ones that promised you'd stay.

The output file is written with mode 644. Running the program twice
produces byte-identical output.
